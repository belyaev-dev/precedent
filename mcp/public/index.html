Precedent

Short, sourced records of how real backend systems were built and how they failed, for agents doing system design.

  • MCP endpoint (Streamable HTTP, read-only, no sign-in): /mcp
  • The whole corpus as one file: /corpus/corpus.json
  • One card: /corpus/cards/<card id>.json
  • Source, licence and how cards are written: github.com/belyaev-dev/precedent

Cards marked "PENDING human review" were checked by machine only.
